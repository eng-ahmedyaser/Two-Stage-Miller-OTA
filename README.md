# Two-Stage-Miller-OTA
Comprehensive design and analysis of a Two-Stage Miller OTA. This project involved meeting rigorous specifications.
### Required Specs:
• Phase Margin: ≥ 70°
• DC Gain: ≥ 66 dB
• Current Consumption: ≤ 60 μA
• Common-Mode Rejection Ratio (CMRR) @ DC: ≥ 74 dB
• Slew Rate: ≥ 5 V/μs
• Output Swing: 0.2 V to 1.6 V
• Load Capacitance: 5 pF
• Static Gain Error: ≤ 0.05%

### Achieved Specs:
• Phase Margin: = 73.84°
• DC Gain: = 70.07 dB
• Current Consumption: = 59.94 μA
• Common-Mode Rejection Ratio (CMRR) @ DC: = 75.74 dB
• Slew Rate: = 5.124 V/μs
• Output Swing: 0.12 V to 1.69 V
• Load Capacitance: 5 pF
• Static Gain Error: ≤ 0.039%

Designed using $g_m/I_D$ methodology with Cadence Virtuoso with CMOS 180nm Technology.
